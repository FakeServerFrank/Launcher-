# Launcher iOS (launcher real para Android)

Subir TODO el contenido de este zip a la raiz de un repo de GitHub (rama main).
El workflow ya va incluido en .github/workflows/build.yml y compila solo al subir.

Si tu app no sube la carpeta oculta .github, crea a mano en GitHub el archivo
.github/workflows/build.yml y pega dentro el contenido de WORKFLOW_build.yml.

APK: pestana Actions -> ultima ejecucion -> Artifacts -> launcher-ios-apk.
Tambien puedes lanzarlo a mano: Actions -> Build APK -> Run workflow.

Usarlo: Ajustes -> Apps -> Apps predeterminadas -> Pantalla de inicio -> Launcher iOS.
